# 博客引擎设计文档总览

> 项目代号暂定 **PenBlog Engine** —— 一款 PHP 8.2+ / MySQL·SQLite 双引擎、自研核心、主题/插件/通知三大子系统全自研、API First 的博客程序。

## 1. 产品定位

| 目标 | 说明 |
|---|---|
| UI 美观、高自定义 | 设计令牌驱动的主题体系,用户不改代码即可深度定制外观 |
| 自研主题系统 | 模板层级继承 + theme.json 设计令牌 + 声明式配置面板 |
| 自研插件系统 | PSR-14 事件总线 + 扩展点注册,给予用户高自定义权限 |
| 自研通知系统 | 五层管线,分类清晰、层次分明的规范化通知 |
| 自研核心引擎 | 所有子系统共同挂载的内核:路由/容器/事件/Extension 模型 |
| API First | 每个数据模型注册即自动生成 REST API,方便外部程序接入 |

## 2. 技术栈

- **语言**:PHP 8.2+(strict_types、enum、readonly)
- **数据库**:MySQL 8.0 / SQLite 3.35+,通过 PDO + 仓储抽象层双方言兼容
- **标准遵循**:PSR-1(自动加载)、PSR-4(命名空间)、PSR-7/15(请求/中间件)、PSR-14(事件)、PSR-3(日志)
- **依赖管理**:Composer,核心零框架(自研内核),仅依赖 psr/* 接口包
- **前端**:原生 HTML/CSS/JS(模板渲染),设计令牌 CSS 变量,无强制框架

## 3. 设计原则

1. **内核极小,子系统挂载**:借鉴 Typecho 的轻量与 Halo 的 Extension 思想,内核只做"路由、容器、事件、模型注册"四件事,其余皆为可插拔子系统。
2. **一切皆 Extension**:文章/分类/标签/评论/页面/菜单/设置/主题/插件配置统一为 `metadata / spec / status` 三段模型,注册即得 CRUD API。
3. **事件驱动解耦**:主题、插件、通知系统之间不直接调用,全部经 PSR-14 事件总线通信。
4. **声明式配置**:主题/插件的设置项由 JSON 声明,后台自动渲染表单(Halo Setting 模型经验)。
5. **API 从第一版即完备**:分页、过滤、鉴权、版本化一次设计到位(Google AIP-158)。
6. **安全默认**:预处理语句、输出转义、CSRF、RBAC、Secret 隔离凭据。

## 5. 里程碑规划(逐步落地)

- **M1 内核**:Kernel + Router + 容器 + 事件总线 + Extension 注册 + PDO 抽象 + 安装向导
- **M2 内容**:文章/分类/标签/页面/评论 CRUD + 默认主题 + 管理后台骨架
- **M3 扩展**:主题系统完整化 + 插件系统 + 扩展点
- **M4 通知**:通知管线 + 站内信/邮件/Webhook 渠道 + 偏好中心
- **M5 API**:OpenAPI 导出 + PAT 鉴权 + Webhook 出站事件 + 应用市场机制
- **M6 打磨**:UI 排版细化、性能、备份、文档站
