# 08 UI/UX 设计方向

> 本篇定**设计语言与方向**;具体排版细节(间距阶梯、组件像素规范)标注为后续迭代项,在 M6 打磨阶段细化。

## 1. 设计语言基调

- 关键词:**克制、可读、纸质感**。博客的本质是长文阅读,UI 服务于内容而非反过来。
- 前台:大量留白 + 单一强调色(来自主题令牌)+ 无装饰性阴影/渐变;后台:信息密度优先,表格化布局。
- 默认主题走"极简编辑部"风格:衬线标题 + 无衬线正文,或整体无衬线,由 theme.json 令牌切换。

## 2. 设计令牌驱动(与 03 对接)

UI 的一切视觉属性来自 CSS 变量(`--color-*`、`--font-*`、`--space-*`、`--radius-*`),由主题 theme.json 编译注入:

- 组件库**禁止硬编码颜色/字号**,保证用户改令牌即深度定制全站。
- 暗色模式:令牌级覆盖(`.theme-dark`),策略 `media`/`class` 二选一;后台提供开关。
- 对比度底线:正文 ≥ 4.5:1,大字号 ≥ 3:1(令牌编译时校验并告警)。

## 3. 布局系统

| 层 | 技术 | 规则 |
|---|---|---|
| 页面级 | CSS Grid + media query | 断点 360/768/1024/1440;主栏+可选侧栏 `minmax(0,1fr) 280px` |
| 组件级 | Flexbox + **容器查询** | 卡片/导航在容器内自适应,不依赖视口 |
| 列表页 | `grid-template-columns: repeat(auto-fill, minmax(320px, 1fr))` | 文章卡片流式排布 |
| 文章页 | 单栏,measure `--content-max: 65–75ch` | 侧注/图宽可溢出正文栏 |

- 视口高度用 `min-height: 100dvh`;表格与代码块包 `overflow-x:auto` 容器。

## 4. 排版方向(细节后续迭代)

- 流式字号:`clamp()` 阶梯(h1/h2/h3/body/small 五级),杜绝逐断点覆写。
- 正文 `line-height: 1.6–1.75`;标题收紧;等宽字体仅用于代码。
- 中文排版:标点挤压、中西文间自动空格(CSS `text-spacing-trim` 渐进增强,JS 兜底)。
- 阅读辅助:进度条、上一篇/下一篇、锚点目录(长文自动生成)。

## 5. 组件规范(方向)

| 组件 | 要点 |
|---|---|
| 文章卡片 | 标题+摘要+meta(时间/分类/标签 chips)+封面;容器查询切紧凑/完整形态 |
| 导航 | 语义 landmark + skip link + `:focus-visible` 可见;移动端抽屉 |
| 表单 | label 常驻(不 placeholder 代替)、行内校验、点击区 ≥44px |
| 评论列表 | 两级嵌套缩进,更深折叠;当前用户高亮 |
| 通知中心 | 铃铛下拉=最近 10 条+未读徽标;独立页按分类 tab 分层(呼应 05 §1) |
| 后台表格 | 批量操作条、列排序、filter 与 API 参数一一对应(06 §4) |
| 空/错/载 | 三态必备:骨架屏(列表)、空态插画位(由主题提供)、错误态带重试 |

- 交互渐进增强:核心阅读零 JS;评论提交、通知轮询等用少量原生 JS。
- 图片:`width/height` 属性防位移、`loading="lazy"`、`srcset/sizes`。

## 6. 管理后台信息架构

```
仪表盘(概览+最近通知)
内容:文章 / 页面 / 分类 / 标签 / 评论(审核队列)
外观:主题列表(激活/设置/子主题) / 菜单 / 自定义代码
插件:列表 / 安装 / 配置区块(SettingSection 自动挂载)
通知:我的通知 / 偏好设置 / 模板 / 投递轨迹与死信
用户:成员 / 角色权限(RBAC 编辑器)
设置:站点 / 阅读 / 写入 / API(PAT 管理 / Webhook)/ 数据库与备份
```

- 后台是 API 的"第一消费者":所有页面只调 `/api/v1`,不另开私有接口 —— dogfooding 保证 API 完备。

## 7. 无障碍与性能底线

- 键盘全流程可用;ARIA 仅在语义不足时补;表单错误与字段 `aria-describedby` 关联。
- 首屏一个 CSS 文件(令牌+关键样式),字体 `font-display: swap` 优先系统栈;前台无框架。
